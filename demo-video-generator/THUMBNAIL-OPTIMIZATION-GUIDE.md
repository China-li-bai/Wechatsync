## 1. 病毒式传播的核心特点

### 1.1 高唤醒情绪触发

内容要引发**高唤醒情绪**才能促进分享：

✅ **正面高唤醒情绪**：

- 兴奋、惊喜、快乐
- 敬畏、惊奇、敬佩
- 好奇、期待、希望

❌ **负面高唤醒情绪**（谨慎使用）：

- 愤怒、愤怒、震惊
- 焦虑、恐惧、担忧

⚠️ **低唤醒情绪**（不利于分享）：

- 悲伤、悲伤、平静
- 放松、满足、厌倦

### 1.2 病毒式内容的7个共同特征

| 特征       | 说明                         | 示例                     |
| ---------- | ---------------------------- | ------------------------ |
| **简洁性** | 信息简单易懂，易于记忆和复述 | "3秒钟学会"              |
| **具体性** | 用具体数字、故事代替抽象概念 | "月入10万" vs "赚很多钱" |
| **意外性** | 打破预期，制造惊喜           | "99%的人不知道"          |
| **可信性** | 提供证据、案例、数据支持     | "100万人验证有效"        |
| **情绪性** | 触动情感，引发共鸣           | "感动到哭"               |
| **故事性** | 用叙事包装信息               | "从负债到逆袭的故事"     |
| **实用性** | 提供价值，帮助解决问题       | "教你如何省钱"           |

### 1.3 分享动机的6个维度

人们分享内容是因为：

1. **社交货币**：分享让我们看起来很棒
2. **实用价值**：帮助他人，显得有用
3. **情绪表达**：表达自己的感受和立场
4. **社会认同**：跟随他人，避免FOMO
5. **自我呈现**：塑造理想的个人形象
6. **关系维护**：加强社交联系

## 2. 排版技巧最佳实践

### 2.1 视觉层次原则

**黄金层次结构（从上到下）：**

```
1. 最强视觉元素（大Emoji/图标/徽章）
   ↓
2. 主标题（最大字号，粗体）
   ↓
3. 副标题（中等字号，衬托）
   ↓
4. 装饰元素（背景、动画、粒子）
   ↓
5. 品牌/标识（最小字号）
```

### 2.2 字体大小层级

| 元素    | 横屏(1280x720) | 竖屏(1080x1920) | 权重        |
| ------- | -------------- | --------------- | ----------- |
| 大Emoji | 200-250px      | 300-380px       | -           |
| 主标题  | 70-90px        | 98-126px        | 900 (Black) |
| 副标题  | 35-45px        | 49-63px         | 600-700     |
| 徽章    | 30-40px        | 42-56px         | 800-900     |

### 2.3 文字对齐与间距

**竖屏对齐原则：**

- ✅ **居中对齐**：最适合竖屏，视觉集中
- ✅ **左对齐**：长篇文案阅读友好
- ❌ **右对齐**：避免使用，除非特殊设计

**行高与间距：**

- 标题行高：1.1-1.3倍
- 副标题行高：1.3-1.5倍
- 段落间距：1.5-2.0倍字号
- 元素间距：20-60px（视重要性）

### 2.4 对比度与可读性

**文字可读性黄金规则：**

1. **对比度 >= 4.5:1**（WCAG AA标准）
2. **浅色背景 + 深色文字** 或 **深色背景 + 浅色文字**
3. **添加文字阴影**提高边缘清晰度：

   ```css
   text-shadow:
     4px 4px 0px #000000,
     -2px -2px 0px #000000;
   ```

4. **描边/轮廓效果**增强可读性：
   ```css
   -webkit-text-stroke: 3px #000000;
   ```

### 2.5 排版禁忌清单

⚠️ **避免这些错误：**

- ❌ 字号太小（竖屏<90px）
- ❌ 文字太多（超过3行主标题）
- ❌ 对比度不足
- ❌ 字间距太窄或太宽
- ❌ 使用过多字体（不超过2种）
- ❌ 文字对齐边缘
- ❌ 颜色过于相近

## 3. 文案写作黄金法则

### 3.1 注意力钩子类型

**8种有效钩子格式：**

| 钩子类型   | 公式                   | 示例                         |
| ---------- | ---------------------- | ---------------------------- |
| **数字型** | [数字] + [结果]        | "3个让你月入过万的秘密"      |
| **疑问型** | [为什么/如何] + [问题] | "为什么聪明人都这么做？"     |
| **命令型** | [动词] + [好处]        | "立即停止！99%的人都错了"    |
| **对比型** | [A vs B] + [差异]      | "普通vs顶尖：差的不是能力"   |
| **秘密型** | [秘密/内幕] + [价值]   | "独家内幕：没人告诉你的真相" |
| **情感型** | [情感词] + [故事]      | "感动到哭：一个普通人的逆袭" |
| **限定型** | [限时/限量] + [紧迫感] | "限时免费：错过再等一年"     |
| **承诺型** | [承诺] + [保证]        | "保证有效：无效退款"         |

### 3.2 强力词库

**增加点击率的强力词汇：**

| 类别       | 词汇                                                         |
| ---------- | ------------------------------------------------------------ |
| **紧迫感** | 紧急、立即、马上、限时、最后、机会、错过、速看、现在、立即   |
| **好奇心** | 秘密、隐藏、真相、揭秘、内幕、没人告诉你、为什么、如何、怎样 |
| **价值感** | 免费、独家、VIP、顶级、最佳、终极、完美、终极、豪华          |
| **情绪**   | 震惊、惊讶、不敢相信、感动、泪目、崩溃、炸裂、疯了吧、离谱   |
| **结果**   | 成功、赚钱、暴富、财富、自由、改变、突破、逆袭、成长         |
| **数量**   | 100万、翻倍、3倍、10倍、100%、零风险、保证                   |

### 3.3 标题字数优化

**最佳标题长度：**

| 平台          | 最佳字数 | 推荐范围 |
| ------------- | -------- | -------- |
| YouTube       | 6-10字   | 5-15字   |
| TikTok/Shorts | 5-8字    | 4-12字   |
| 通用          | 7-10字   | 6-14字   |

**原则：**

- 简短有力，一目了然
- 包含关键词
- 留有想象空间
- 避免完整句子

### 3.4 副标题写作技巧

**副标题的3个作用：**

1. 补充信息
2. 增强可信度
3. 消除疑虑

**副标题公式：**

```
[主标题]
+ "因为..." / "方法是..." / "答案是..."
+ [具体解释/数据/案例]
```

**示例：**

```
震惊！这个秘密让100万人赚到了第一桶金
答案会让你大吃一惊...
```

### 3.5 文案禁忌

⚠️ **避免这些：**

- ❌ 使用专业术语（保持简单）
- ❌ 承诺不切实际（如"一夜暴富"）
- ❌ 负面词汇过多
- ❌ 冗长复杂
- ❌ 模糊不清（"很好" vs "月入10万"）

## 4. STEPPS法则深度解析

### 4.1 S - Social Currency（社交货币）

**核心思想：** 分享让我们看起来很棒

**应用技巧：**

- 使用"独家"、"内幕"、"VIP"等词
- 强调稀有性和稀缺性
- 暗示知道的人很少
- 让分享者显得聪明、有见识

**徽章推荐：** 独家、内幕、TOP1、VIP

### 4.2 T - Triggers（诱因）

**核心思想：** 利用环境线索触发记忆

**应用技巧：**

- 使用"每天"、"早上"、"咖啡"等日常词汇
- 与热门话题关联
- 利用节假日、季节
- 创建内部梗或口号

**徽章推荐：** 每日、提醒、注意、每日一题

### 4.3 E - Emotion（情绪）

**核心思想：** 激发高唤醒情绪

**应用技巧：**

- 使用"震惊"、"感动"、"愤怒"等词
- 讲述有情感的故事
- 创造惊喜和意外
- 利用表情符号增强情感

**徽章推荐：** 震惊、感动、HOT、必看

### 4.4 P - Public（公开性）

**核心思想：** 让产品/思想可见

**应用技巧：**

- 展示"100万人"、"99%的人"
- 使用前后对比
- 展示真实案例和结果
- 强调已被验证

**徽章推荐：** 真实、实测、见证、已验证

### 4.5 P - Practical Value（实用价值）

**核心思想：** 提供有用信息

**应用技巧：**

- 使用"教程"、"方法"、"技巧"
- 承诺具体结果
- 提供可操作步骤
- 强调节省时间/金钱

**徽章推荐：** 教程、技巧、免费、干货

### 4.6 S - Stories（故事）

**核心思想：** 用叙事包装信息

**应用技巧：**

- 使用"故事"、"经历"、"真实"
- 讲述个人成长
- 包含转折和逆袭
- 有情感起伏

**徽章推荐：** 真实故事、感人、治愈、励志

## 6. 竖屏设计特殊指南

### 6.1 竖屏黄金区域

**手机屏幕视觉热点（从上到下）：**

```
┌─────────────────┐
│  顶部安全区域   │  ← 标题、徽章、重要信息
│   (0-30%)       │
├─────────────────┤
│                 │
│  核心视觉区     │  ← 大Emoji、主标题
│   (30-70%)      │     放最重要的内容
│                 │
├─────────────────┤
│  底部区域       │  ← 副标题、CTA、装饰
│   (70-100%)     │
└─────────────────┘
```

### 6.2 竖屏排版要点

✅ **一定要做：**

- 所有内容居中对齐
- 字体放大1.4倍（相比横屏）
- 关键信息放在屏幕上半部分
- 使用垂直滚动流（从上到下）
- 保持足够的边距（两侧各60-100px）

❌ **避免：**

- 横屏内容直接裁剪
- 文字紧贴边缘
- 过多内容挤在一屏
- 小字体难以阅读

### 6.3 平台适配参数

| 平台                | 尺寸      | 比例 | 重点               |
| ------------------- | --------- | ---- | ------------------ |
| **TikTok**          | 1080x1920 | 9:16 | 情感、趋势、挑战   |
| **YouTube Shorts**  | 1080x1920 | 9:16 | 快速、教程、娱乐   |
| **Instagram Reels** | 1080x1920 | 9:16 | 美观、创意、音乐   |
| **小红书**          | 1080x1920 | 9:16 | 实用、种草、生活   |
| **普通YouTube**     | 1280x720  | 16:9 | 详细、深度、长内容 |

## 总结

优秀的封面设计 = **心理学** + **视觉美学** + **实用价值**

记住：

- 🎯 **目标明确**：知道你要传达什么
- 😊 **情感优先**：先触动情绪，再传达信息
- 🔍 **简单有力**：少即是多，突出重点
- 📱 **平台适配**：为目标平台优化
- 🧪 **测试迭代**：A/B测试找到最佳方案
