## 🎯 系统概述

本系统是一个**基于HTML/CSS + Playwright**的视频封面生成器，专为**高CTR（点击率）**设计。包含**53个模板**、**24个CSS表情**、**7种配色方案**，支持**竖屏/横屏**自适应。

### 5. MrBeast风格模板 - 2个

| 模板文件 | 特点 | 设计理念 |
|---------|------|---------|
| `mrbeast-style-v1.html` | 经典红底 | 传统MrBeast风格 |
| `mrbeast-2026-v2.html` | 2026新版 | 悲伤悖论、数学构图 |

**MrBeast 2026设计哲学**:
- **悲伤悖论**: 使用焦虑/悲伤表情而非夸张喜悦
- **40-60%脸规则**: 面部占画面40-60%
- **60-30-10色彩规则**: 60%主色+30%辅色+10%点缀
- **三层深度系统**: 前景/中景/背景
- **0-5字限制**: 极简文案

**适用场景**: 挑战视频、高CTR需求、YouTube封面

## ✨ 核心功能

### 1. 智能模板推荐

```python
from lib.thumbnail_generator import CodeBasedThumbnailGenerator

generator = CodeBasedThumbnailGenerator()

# 自动推荐最佳模板
recommendation = generator.recommend_template("震惊！这个方法让我月入10万")
# 返回: {
#   'template': 'viral-vertical',
#   'color_scheme': 'shock_red',
#   'emotions': ['shock', 'success'],
#   'config': {...}
# }
```

### 2. 情绪触发词检测

```python
# 自动检测情绪关键词
emotions = validator.detect_emotional_triggers("震惊！不可思议的秘密")
# 返回: ['shock', 'curiosity']
```

**情绪触发词库**:
- **震惊**: 震惊、惊讶、不敢相信、竟然、居然、天啊、崩溃、炸裂
- **好奇**: 秘密、隐藏、真相、揭秘、内幕、为什么、如何
- **紧迫**: 紧急、立即、马上、限时、最后、机会、错过、倒计时
- **情感**: 感动、泪目、哭了、心碎、温暖、治愈、励志
- **成功**: 成功、赚钱、暴富、财富、自由、月入、百万、翻倍

### 3. A/B测试支持

```python
# 生成多个变体
variants = generator.generate_ab_variants(
    base_config,
    variations=['color', 'font_size', 'badge']
)
# 返回多个变体文件路径
```

### 4. 竖屏自动适配

```python
# 自动检测并切换竖屏模板
config = {
    "template": "viral",  # 自动选择 viral-vertical
    "width": 1080,
    "height": 1920
}
```

### 5. 封面审查系统

```python
from lib.thumbnail_auditor import audit_thumbnail

report = audit_thumbnail(config)
print(f"评分: {report.overall_score}/100")
print(f"是否通过: {report.passed}")
print(f"改进建议: {report.suggestions}")
```

## 🚀 使用方法

### 基础使用

```python
from lib.thumbnail_generator import CodeBasedThumbnailGenerator

generator = CodeBasedThumbnailGenerator()

# 基础配置
config = {
    "template": "viral-vertical",
    "title": "震惊！这个方法太神奇了",
    "subtitle": "99%的人都不知道",
    "width": 1080,
    "height": 1920
}

# 生成封面
output_path = generator.generate(config=config)
print(f"封面已生成: {output_path}")
```

### 智能推荐

```python
# 让系统自动推荐
recommendation = generator.recommend_template("紧急通知！最后24小时")
config = recommendation['config']
output_path = generator.generate(config=config)
```

### 使用表情模板

```python
# 直接使用表情
config = {
    "template": "templates/thumbnails/emotions/emotion-shocked.html",
    "title": "震惊",
    "subtitle": "Unbelievable!"
}
output_path = generator.generate(config=config)
```

config = {
