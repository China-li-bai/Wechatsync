# 更新日志

所有重要的更改都将记录在此文件中。

## [1.1.0] - 2026-03-30

### 新增功能

#### 🎬 自动录制集成

- **VideoRecorder 模块**: 新增视频录制器模块，支持全自动录制
  - 自动打开浏览器并访问目标网页
  - 自动开始和停止录制
  - 支持根据语音时长精确控制录制时长
  - 支持自动执行操作（滚动、截图等）
  - 完善的错误处理和日志记录

- **录制配置**: 配置文件新增 `recording` 配置项
  - `enabled`: 启用/禁用自动录制
  - `auto_scroll`: 自动滚动页面
  - `scroll_distance`: 默认滚动距离
  - `wait_after_action`: 动作后等待时间

#### 📊 进度显示

- **进度条**: 添加进度条显示（需要安装 tqdm）
  - 显示总体进度百分比
  - 显示当前执行步骤
  - 语音生成时显示进度条

- **步骤提示**: 改进步骤提示信息
  - 使用进度条显示各阶段进度
  - 清晰的步骤划分（语音、字幕、录制、合成）

#### 🛠️ 错误处理改进

- **详细错误提示**: 改进错误提示信息
  - 清晰的错误原因说明
  - 建议的解决方案
  - 错误堆栈跟踪

- **日志记录**: 添加详细的日志记录
  - 控制台日志输出
  - 不同级别的日志（INFO、WARNING、ERROR）
  - 时间戳和日志级别显示

- **错误恢复**: 改进错误恢复机制
  - 捕获并处理各种异常
  - 提供有意义的错误信息
  - 支持部分恢复

### 改进

#### 核心引擎优化

- **模块化设计**: 改进代码结构
  - 新增 `VideoRecorder` 类
  - 改进 `DemoVideoGenerator` 类
  - 更好的模块间解耦

- **日志系统集成**: 所有模块支持日志
  - `ConfigParser` 支持日志
  - `VoiceoverGenerator` 支持日志
  - `SubtitleGenerator` 支持日志
  - `VideoComposer` 支持日志

- **配置验证**: 改进配置文件验证
  - 更详细的验证信息
  - 支持可选配置项
  - 更好的默认值处理

#### 用户体验提升

- **命令行参数**: 改进命令行参数
  - `--no-auto-record`: 禁用自动录制
  - `--log-level`: 设置日志级别

- **输出信息**: 改进控制台输出
  - 更清晰的进度显示
  - 更详细的错误信息
