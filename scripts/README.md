1. **多平台热榜抓取**：今日头条、知乎、简书、微信公众号

### 方法2：使用Python爬虫脚本

**适合人群**：开发者、需要定制化

#### 第一步：安装依赖

```bash
pip install requests beautifulsoup4 pandas
```

#### 第二步：运行爬虫

```bash
cd /Users/mac/project/Wechatsync/scripts
python hot_article_crawler.py
```

#### 第三步：查看结果

脚本会生成两个文件：
- `original_hot_articles.json` - 原始文章数据
- `original_hot_articles.csv` - CSV格式数据

运行脚本后，选择是否使用AI改写：
- 输入 `y` 确认改写
- 输入智谱AI的API密钥
- 等待改写完成

生成的文件：
- `rewritten_hot_articles.json` - 改写后的文章
- `rewritten_hot_articles.csv` - CSV格式

## 🔧 高级配置

### 1. 定时抓取

创建定时任务：

**Linux/Mac (crontab)**：
```bash
# 编辑crontab
crontab -e

# 添加定时任务（每6小时执行一次）
0 */6 * * * cd /Users/mac/project/Wechatsync/scripts && python hot_article_crawler.py
```

**Windows (任务计划程序)**：
1. 打开"任务计划程序"
2. 创建基本任务
3. 设置触发器：每6小时
4. 设置操作：启动Python脚本

### 2. 代理设置

如果需要使用代理：

```python
# 在爬虫类中添加
proxies = {
    'http': 'http://your-proxy:port',
    'https': 'http://your-proxy:port'
}

response = self.session.get(url, proxies=proxies)
```

### 3. Cookie配置

某些平台需要登录才能访问：

```python
# 在headers中添加cookie
headers = {
    'User-Agent': 'Mozilla/5.0...',
```

## ⚠️ 注意事项

### 法律合规

1. **遵守robots.txt**
   - 每个网站都有robots.txt文件
   - 例如：https://www.zhihu.com/robots.txt
   - 不要抓取禁止的内容

2. **合理请求频率**
   - 设置请求间隔（3-5秒）
   - 避免高峰时段爬取
   - 限制数据量

3. **数据使用**
   - 不抓取个人隐私数据
   - 商业使用需获得授权
   - 遵守《网络安全法》

### 技术要点

1. **反爬虫应对**
   - 随机User-Agent
   - 使用代理IP
   - 模拟人类行为

2. **异常处理**
   - 网络超时重试
   - 数据格式验证
   - 错误日志记录

3. **数据清洗**
   - 去除HTML标签
   - 去除空白字符
   - 数据去重

## 💬 常见问题

### Q1: 如何获取智谱AI的API密钥？

**A**: 
1. 访问 https://open.bigmodel.cn/
2. 注册并登录
3. 进入"API密钥"页面
4. 创建新的API密钥

### Q2: 爬虫被封IP怎么办？

**A**:
1. 使用代理IP池
2. 降低请求频率
3. 随机User-Agent
4. 模拟人类行为

### Q3: 改写后的文章质量如何？

**A**:
- AI改写可以保持原意并改变表达
- 建议人工审核和优化
- 添加个人见解提升价值

### Q4: 可以抓取其他平台吗？

**A**:
- 可以，需要分析目标平台的网页结构
- 修改爬虫脚本中的选择器
- 注意遵守平台的robots.txt

### Q5: 如何批量改写文章？

**A**:
- 使用`batch_rewrite`方法
- 设置合理的请求间隔
- 监控API调用次数
